# Contribuindo com o Off3D Studio 🚀

Primeiramente, obrigada por se interessar em colaborar! Este é um projeto Open Source focado em aprendizado e construção de portfólio real.

### Como começar?
1. Dê um **Fork** no repositório.
2. Escolha uma **Issue** com a label `help wanted` ou `good first issue`.
3. Crie uma branch para sua feature: `git checkout -b feature/minha-feature`.
4. Após finalizar, abra um **Pull Request** detalhando suas mudanças.

### O que estamos buscando no Front-end?
Estamos iniciando a estrutura em **Angular**. Se você quer sugerir uma arquitetura ou começar um componente, sinta-se à vontade para abrir uma Discussion ou comentar nas Issues abertas!

**Bora codar!** ✨
